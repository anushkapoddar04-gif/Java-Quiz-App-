# Java Quiz Application

A beginner-friendly console-based Quiz Application developed using Java.

## About the Project

This is my first Java project and my first project uploaded to GitHub.

The application asks multiple-choice questions and checks the user's answers. At the end, it calculates the score, percentage, correct answers, and wrong answers.

## Features

* Multiple-choice questions
* Java and DSA questions
* Randomized questions
* User name input
* Answer validation
* Score calculation
* Percentage calculation
* Final performance message
* Input validation for A/B/C/D
* Object-Oriented Programming structure

## Technologies Used

* Java
* Java Collections
* Object-Oriented Programming
* ArrayList
* Scanner

## How to Run

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project

Open the project folder in VS Code or any Java IDE.

### 3. Compile the program

```bash
javac src/*.java
```

### 4. Run the application

```bash
java -cp src Main
```
